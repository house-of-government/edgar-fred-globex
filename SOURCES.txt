Additional HDFGroup test families worth following later
-------------------------------------------------------
- groups with compact/dense link storage
- chunked datasets and multiple chunk-index versions
- filters/compression/checksums
- attributes and named datatypes
- references and heaps
- external links/storage
- virtual datasets
- superblock/object-header version compatibility
- SWMR-format metadata
- intentionally corrupted files

Documentation policy
--------------------
Link the official HDF5 Field Guide/file-format documentation. Mirror only compact binary fixtures whose source licensing permits redistribution; keep the larger official test corpus upstream until a specific structural distinction is needed.
