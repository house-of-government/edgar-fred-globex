d6fd56f52d904c605fb1cc493bfd40fc976e7c0b

sample-small.tif
  Path: autotest/gcore/data/byte.tif
  Source blob SHA: 6fddac1286241fd62383c20965a11c38f021d7bc

sample-complex.tif

Additional useful GDAL specimens for later expansion
----------------------------------------------------
- `rgbsmall.tif` — RGB/multiband image
- tiled/interleave variants created by GDAL TIFF tests
- palette/color-table images
- compressed TIFFs (LZW/Deflate/JPEG/etc.)
- mask/alpha configurations
- multi-IFD / overview/SubIFD cases
- BigTIFF
- sparse/large-offset/corruption cases

Those should be added when they expose a parser or backend distinction beyond the two current specimens rather than merely increasing file count.

Documentation policy
--------------------
Link TIFF/GeoTIFF standards and GDAL driver documentation. Mirror the compact test binaries whose upstream redistribution is covered by GDAL's licensing; do not duplicate entire manuals here.
